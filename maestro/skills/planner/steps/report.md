# Report progress

Read the goal's epic on the board. Count its tickets and the tickets that block it as ready, in flight, blocked or closed. For closed work, cite the merged change and the check that shows the result. For work in flight, name the owner, cite the latest result you can check, and say what remains.

For blocked work, use the groups from `steps/unblock.md` and say what each group needs before work can resume.
