# Plan a goal

Fill what the goal leaves open from the repo. Send calls that change the goal or scope to the chief of staff through `steps/unblock.md`.

Find or create the board epic `maestro-goal-<slug>` for the goal. Use `steps/create-ticket.md` for each part of the goal. Check that the tickets together cover it.

Put each prerequisite before the tickets that need it. Let independent tickets run at the same time. Follow the ready-ticket order in `maestro-planner` and start work with `steps/assign-ticket.md`.
