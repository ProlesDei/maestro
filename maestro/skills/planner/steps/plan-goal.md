# Plan a goal

Find or create the board epic `maestro-goal-<slug>` and save the full goal brief in its description.

If the epic marks planning complete, stop here (see “Ticket board”).

Read the repo and the owner calls on the epic. Use recorded answers and send new calls through `steps/unblock.md`. Wait for answers before filing tickets.

Group each feature's tickets you expect to be ready for QA together into a batch with a unique name. Reuse batches already filed for the same work. Put a ticket in a later batch than any ticket it waits on. Put tickets with overlapping Touches paths in different batches.

Reuse tickets already on the epic and file only missing work with `steps/create-ticket.md`. Check that the tickets together cover the goal, then mark planning complete on the epic.
