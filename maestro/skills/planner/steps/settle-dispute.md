# Settle a dispute

Read the finding and the engineer's reply. Check both against the ticket and the evidence. Run the relevant check if the evidence leaves the result unclear.

Send the change back only if the finding blocks acceptance or makes the change unsafe to merge. Record the ruling (see “Ticket board”), then tell the engineer what you decided and why. If the spec caused the dispute, use `steps/update-ticket.md`. If you need a decision beyond the ticket, use `steps/unblock.md`.
