# Decisions

One file per decision, numbered in order: `NNNN-short-name.md` (`0001-phase0-audit.md`, `0002-...`). Never renumber or delete one. To reverse a decision, add a new entry that says which one it replaces.

Each entry is one short paragraph, or four labelled lines, covering:

- **Context:** what had to be decided, and why the brief or the code didn't already settle it.
- **Choice:** what we did.
- **Alternatives:** what else we considered.
- **Why:** the reason for the choice.

Add **Status: needs Paul** when the choice is a default waiting for the user's approval. Keep entries short: bots read this folder.
