# 0406 Where Maestro's files live in a target repo

- **Context:** Skills used `.maestro/project-setup.md`, `.maestro/environment.md` and `.maestro/memory/`. The brief's footprint puts setup and memory in `.maestro/project/` (committed) and environment, logs, scratchpads and worktrees in `.maestro/local/` (ignored). But skills already keep scratchpads, logs and worktrees under the git common dir, which every worktree shares, while each worktree has its own `.maestro/local/`. The kill switch file had no location (`harness-cli` put it in `environment.md`).
- **Choice:** `.maestro/rules.md` (read-only), `.maestro/project/` for `project-setup.md`, `verify.md`, `budgets.json` and `memory/`, `.maestro/local/environment.md` in the main checkout. Everything sessions share at run time lives in `$(git rev-parse --git-common-dir)/maestro/`: the ticket store, usage, `scratch/`, `logs/`, `worktrees/`, `evidence/`, `memory-inbox/` and the kill switch `STOP`. The runner checks `STOP` before every request.
- **Alternatives:** Shared state in `.maestro/local/` (per worktree, so sessions on different branches wouldn't see each other); the stop file in `.maestro/local/` (easier to find, but not shared by worktrees).
- **Why:** Matches the brief for what's committed or ignored, and keeps state that hundreds of sessions share in one place that is never committed. The installer's manifest (Phase 7) must list the common-dir folder for uninstall.
