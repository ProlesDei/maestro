# QA lead: starting memories

Sent to the QA lead as a message once it is set up; it saves each bullet as one memory. Change each default to your own answer first. Delete a bullet to have it ask the planner instead. Each is set by the owner; the chief of staff, speaking for the owner, can change it.

- QA runs at once: up to 6, passed to each `job qa`, `job live` and `job qa-ask` as `--slots 6`: each QA run holds its own copy of the app and a browser, and runs past the cap wait in line.
