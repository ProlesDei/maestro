# Report progress

Group tickets as done, in flight, or blocked. For done work, cite the merged change and the check that shows the result. For work in flight, name the owner, cite the latest result you can check, and say what remains.

For blocked work, use the groups from `maestro-unblock` and say what each group needs before work can resume.
