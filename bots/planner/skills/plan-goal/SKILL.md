# Plan a goal

Use `maestro-create-ticket` for each part of the brief. Check that the tickets together cover what the brief calls for.

Put each prerequisite before the tickets that need it. Let independent tickets run at the same time. Follow the ready-ticket order in `maestro-planner` and start work with `maestro-assign-ticket`.
